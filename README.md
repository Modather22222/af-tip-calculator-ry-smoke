# Tip Calculator
A Material 3 tip calculator for splitting a bill without the mental math.
Enter a bill amount, drag the slider to choose a 0–40% tip, and split the total between 1–20 people. Every value updates live, including each person's share.
Tap any person under "Who pays?" to mark the payer; that person moves to the top of the split list.

## Run
`flutter pub get`, then `flutter run`.
